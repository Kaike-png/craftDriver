Correções de inicialização.

- Logo após entrar na sessão, uma conta podia aparecer como "Entre novamente" por cerca de 30 s, enquanto o KWallet terminava de abrir. Agora o craftDriver tenta ler o chaveiro de novo por alguns segundos antes de pedir login.
- Abrir o craftDriver pelo menu enquanto uma instância `--headless` está rodando não fica mais sem resposta: aparece um aviso explicando como encerrá-la.
- `craftdriver --minimized` com o app já aberto não traz a janela para a frente (autostart duplicado).

## Instalar
| Distro | Comando |
|---|---|
| Arch, Garuda, Manjaro | `sudo pacman -U craftdriver-bin-0.1.3-1-x86_64.pkg.tar.zst` |
| Debian, Ubuntu, Mint | `sudo apt install ./craftdriver_0.1.3-1_amd64.deb` |
| Fedora, openSUSE | `sudo dnf install ./craftdriver-0.1.3-1.x86_64.rpm` |
