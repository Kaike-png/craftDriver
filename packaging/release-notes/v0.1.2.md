Correção: as contas pediam login de novo depois de reiniciar em sessões fora do Plasma/GNOME (Hyprland, Sway, i3…).

## O que mudou
- Na inicialização, o craftDriver aciona o serviço do chaveiro se ele não estiver rodando. No KWallet 6 o serviço `ksecretd` não sobe sozinho fora do Plasma.
- Se você já entrou nas contas, o app espera o chaveiro, por até 60 s, em vez de passar a usar um arquivo de tokens vazio. Antes, isso fazia todas as contas pedirem login.
- Se o chaveiro não responder, a mensagem diz isso, em vez de "Entre novamente".

## Hyprland / Sway com KWallet
Para a carteira abrir sem pedir senha, adicione ao autostart do compositor, antes do craftDriver:

```
exec-once = /usr/lib/pam_kwallet_init
```

É o que o Plasma faz ao iniciar a sessão. Requer o `kwallet-pam` e a senha da carteira igual à senha de login.

## Instalar
| Distro | Comando |
|---|---|
| Arch, Garuda, Manjaro | `sudo pacman -U craftdriver-bin-0.1.2-1-x86_64.pkg.tar.zst` |
| Debian, Ubuntu, Mint | `sudo apt install ./craftdriver_0.1.2-1_amd64.deb` |
| Fedora, openSUSE | `sudo dnf install ./craftdriver-0.1.2-1.x86_64.rpm` |
